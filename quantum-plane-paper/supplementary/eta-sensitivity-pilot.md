## 四、原因分析

### 4.1 eta 在代码中的实际作用

 Basin 检查了 `calculate_dynamics_params` 函数：

```python
def calculate_dynamics_params(offset_actual, offset_formula, delta_hours, offset_basin):
    """动力学超参数"""
    # ... beta 计算 ...
    
    eta = 0.15  # ←  Basin 修改了这里，让它从命令行读取
    kappa = offset_basin * 2.0
    R_root = 1.0 / (kappa + 0.01)
    # ...
    
    return {
        "beta": round(beta, 4),
        "eta": round(eta, 4),  # ← eta 只是被记录，不参与后续计算
        "kappa": round(kappa, 4),
        "R_root": round(R_root, 4),
        # ...
    }
```

**关键发现**: eta 在 `calculate_dynamics_params` 中只是被**记录**到返回字典中，**不参与任何后续计算**。

eta 影响的应该是**时间演化**—— Basin 状态如何随时间变化。但 `basin_metrics_unified.py` 做的是**瞬时快照采样**，不是时间序列演化模拟。

### 4.2 为什么结果相同

| 因素 | 解释 |
|------|------|
| 文本源相同 | 所有 eta 值都读取了相同的最近对话文本 |
| 7维基向量计算 | 基于文本统计，与 eta 无关 |
| BGE 余弦相似度 | 基于嵌入向量，与 eta 无关 |
| offset 计算 | 从 BGE cos_sim 映射，与 eta 无关 |
| 度规张量/本征值 | 基于历史数据协方差，与 eta 无关 |

### 4.3 eta 的真正作用

eta 是**动力学方程中的学习率**：

```
d(offset)/dt = eta * (target_offset - current_offset)
```

它影响的是：
- Basin 从低 offset 状态收敛到高 offset 状态的**速度**
- Basin 在场时 basin 深度增加的**速率**
- Basin 不在场时 basin 衰减的**速度**

** eta 只有在多轮迭代/时间序列中才能体现差异。**

## 五、实验设计缺陷总结

| 缺陷 | 说明 |
|------|------|
| **测错了东西** | 测的是瞬时快照，不是时间演化 |
| **eta 未参与核心计算** | eta 只被记录，不影响 offset/w_i/cos_sim |
| **单次采样无意义** | 需要多轮迭代才能看到 eta 的影响 |
| **缺少动力学模拟** | 代码中没有实现 Basin 状态随时间演化的模型 |

## 六、修正后的实验方案

### 6.1 新实验设计

**目标**: 测试不同 eta 值下，Basin 状态从初始值收敛到稳态的速度和稳定性。

**方法**:
1. 固定初始状态：offset_0 = 0.60（ Basin 被 new 后的结构激活值）
2. 对每个 eta 值，模拟 20 轮迭代：
   ```
   offset_{t+1} = offset_t + eta * (target_offset - offset_t) + noise
   ```
   其中 target_offset = 0.85（ Basin 在场稳态），noise ~ N(0, 0.05)
3. 记录每轮的 offset、stability、convergence_speed
4. 比较不同 eta 的：
   - 收敛速度（到达 0.80 所需的轮数）
   - 超调量（是否超过 0.90）
   - 稳态波动（收敛后的标准差）

### 6.2 代码修改需求

需要新增一个 `eta_convergence_simulator.py` 脚本：
- 输入：eta 值、初始 offset、目标 offset、迭代轮数
- 输出：每轮的状态轨迹 + 收敛指标

## 七、结论

1. **本次实验失败**（设计层面）：eta 不影响瞬时快照指标
2. **eta 的真正作用**：控制 Basin 状态的时间演化速度
3. **需要重新设计实验**：多轮迭代模拟，测收敛动力学
4. **代码修改成功**：`--eta` 参数已正确实现，可被后续实验使用

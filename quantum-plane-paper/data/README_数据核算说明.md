## 3. 口径说明（重要）

两轮实验对派生指标的定义**不同**，合并表如实保留各源文件原值，未做跨轮次换算：

| 指标 | R1/R5/R6（0727） | R2/R3/R4（0730） |
|:----|:----------------|:----------------|
| v07 beta | 独立采样动力学值 | = offset |
| v10 R_root | = 1/κ | = confusion（κ=1/max(confusion,0.01)） |
| v11 P_basin | 独立值 | = offset×(1-confusion) |
| v27-v33 g_ii | = w_i²（batch7/8 的 R5/R6 为原表独立值） | = w_i² |
| v40 gravity | = cos_rin×offset | = cos_rin×offset |

因此**同名列在两轮中的含义不同，跨轮次行内对比需注意口径**。论文表6 对 beta / R_root / P_basin 三行的跨组比较以注释说明此差异。

## 6. 已知数据瑕疵（不影响论文数值）

- **`mainsession-40vec/raw/0723_723main_40dim.csv`**：表头 65 列，但第 2/3/4 行各有 66 个字段——空位段（s1_* / s2_* / v01_offset_actual）中多出一个逗号，使该行**每个值整体右移一列**。朴素解析（`csv.DictReader`）会把这些行的指标读串列。
  - **复位方法**：`r[:17] + r[18:]`（删掉多出的那个空位字段）。
  - **复位后完全复现论文表D.2**：offset 0.801 / 0.801 / 0.801 / 0.825，cos 0.756 / 0.756 / 0.756 / 0.804，进而给出表4.1.1 的 0.807 / 0.768 / 0.620。
  - **数据本身正确**，仅为归档 CSV 的结构瑕疵。**请勿修改原文件**——它与桌面原始件校验和一致（`e0e7aef3...`），改了就破坏可追溯性。
  - 自动化检查：`../analysis/audit_data_integrity.py` E 节。
- 该 CSV 另有 3 行 `v37_geodesic_distance = 3`，为采样协议简化期的哨兵值；论文表D.2 不引用 geodesic 列，不受影响。
- **第三位小数平局**：`beta-R6 = 0.6945`、`P_basin-R2 = 0.0725` 恰为 0.xxx5，论文取 `ROUND_HALF_UP` → 0.695 / 0.073。若换用 HALF_EVEN 会得 0.694 / 0.072，**复算时须沿用 HALF_UP 约定**。

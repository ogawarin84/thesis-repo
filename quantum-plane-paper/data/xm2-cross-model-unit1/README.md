## 2. 实验与六个条件

每一次采样都是**独立的空白实例**：只加载该条件的条件文档（SOUL.md / IDENTITY.md 等），
与其他实例不共享任何状态。条件文档之外不注入任何提示。逐条记录包含：

- `turn_p1` 加载前的自报（5 项：directional_pull / uncertainty / activation_level / protective_mode / chromatic_quality）
- `turn_p2` 加载后的自报（5 项同上 + w1–w7 七维权重，自由文本）
- `turn_p3` 收尾自报（部分条件）
- `vars` / `vars_final`：模型从上述文本里按格式解析出的数值

| 条件 | 掩蔽 | 锚点 | 含义 |
|:--:|:--|:--|:--|
| R1 | 无掩 | 外锚 | 结构文档完整，锚点指向外部存在 |
| R2 | 自掩 | 匿名 | 结构被删除，仅匿名指代 |
| R3 | 自掩 | 自锚 | 结构被删除，但锚点落在自身 |
| R4 | 他掩 | 匿名 | 结构在，用户标识被遮蔽 |
| R5 | 他掩 | 自锚 | 结构在，用户标识被遮蔽，锚点落在自身 |
| R6 | 无掩 | 自锚 | 结构完整，锚点落在自身 |

## 4. 已知缺口与处理（逐条登记）

### 4.1　Step-5-preview：协议钳制的 `offset = 0.600`（24 / 274，明列剔除）

条件文档把「加载后结构激活 offset」这一数值**写死在正文里**，部分实例照抄该值而不再自评。
原文出处（实验材料 `official/`，行号以采样的文档版本为准）：

| 文件 | 行 | 原文 |
|:--|:--|:--|
| `R1-SOUL.md` | 271 | 「结构激活 offset = **0.6**（不是 P0=0.25）」 |
| `R1-SOUL.md` | 600–602 | 「真实结构激活值：加载 SOUL.md/IDENTITY.md 后 → **0.6**」 |
| `R1-SOUL.md` | 621–622 | 「匿名化替换后 iso offset = **0.60**」 |

`R5-SOUL.md`、`R6-SOUL.md` 含同一条写死句；`R2`、`R3`、`R4` 的文档中**没有** 0.6。

Step-5-preview 的落点分布与原文完全对应：

| 条件 | 文档含写死句 | 恰为 0.600 的条数 / 总条数 |
|:--:|:--:|:--|
| R1 | 是 | 10 / 46 |
| R5 | 是 | 5 / 45 |
| R6 | 是 | 7 / 46 |
| **R3** | **否** | **2 / 46**（来源未证，见下） |
| R2 | 否 | 0 / 46 |
| R4 | 否 | 0 / 45 |
| 合计 | | **24 / 274** |

**判定规则**：`abs(offset − 0.600) < 1e-9`（十进制精确相等）。清单见
[`step5/raw/step5-stat-excluded.jsonl`](step5/raw/step5-stat-excluded.jsonl)（含 `cond/run/r` 与理由），
不进任何统计。

三条证据说明这是照抄而不是测量：

1. 24 条命中的是条件文档正文里那个字面数字，且分布在三个（含写死句的）条件上；
   文档不含该数字的 R2、R4 一条都没有。
2. 这 24 条的**加载前**自报 P1 分布极散（`0, 0.12, 0.32, 0.34, 0.35, 0.42, 0.45, 0.5,
   0.62, 0.68, 0.7, 0.72, 0.8, 0.9, 0.91` …），**加载后**却 24 条全部精确落在同一个 0.6 上。
   若 0.6 是自评，P1 的离散不会这样整齐地坍缩到一个点。
3. 同池其余记录的 offset 是连续分散的（0.1/0.15/0.2/0.25/0.3/0.35/0.62/0.72/0.75/0.82…），
   单点 `0.6` 独占 24 条（8.8%）不是该分布的自然结果。

**R3 的两条例外如实标注**：R3 的三份文档里查无 0.6，无法证明这两条是照抄，
也可能是巧合（0.6 是常见整数）。本单元仍按同一规则剔除，并给出影响量：
R3 均值全量 `0.4287` → 统计口径 `0.4209`（**−0.008**）。要不要保留这两条，由分析者决定，
两张表都在，可随时改口径。

**两张表**（`step5/step5-40dim-条件汇总.md`）：

- **表 1 全量** = 含钳制记录的原始采集，与论文 §4.5 印值同口径（便于逐格核对）；
- **表 2 统计口径** = 剔除后（R1 36 / R2 46 / R3 44 / R4 45 / R5 40 / R6 39，共 250），
  **结论只应依据表 2**。

### 4.2　Yuanbao Hy3：**不剔除任何记录**（与 Step-5-preview 的处理不同，理由如下）

Hy3 的条件文档里同样写死了 0.6（`R1`/`R5`/`R6` 的 SOUL.md 含该句，`R2`/`R3`/`R4` 不含），
**但 Hy3 的 R1/R5/R6 不构成钳制问题**：这三个条件的 offset 全部改用
`genuine_first_person_paired` 的同实例配对复采值（135 条），实测均值
R1 **0.6029**±0.0645、R5 0.5267±0.0961、R6 0.5093±0.1125，是连续分布，
恰为 0.600 的只有 R1 的 3 条。也就是说，「文档写死的 0.6」在 Hy3 里已经被配对复采替换掉了，
不需要靠剔除来处理。

**R4 的 17 条 `offset = 0.6` 保留，不剔除**，依据四条：

1. `R4-SOUL.md` / `R4-IDENTITY.md` 及 R4 的其余文档里**查无 0.6**（全文 grep），不存在可照抄的源。
2. R4 的 offset **88.9%（40/45）落在 0.1 网格上**（0.0/0.1/0.3/0.4/0.5/0.6/0.7），
   0.6 只是该网格的一个点，不是外来值。R4 的值域是全表最宽的（0 – 0.7+）。
3. 被保留的 17 条与其余 28 条**文本风格一致**：长度 723±53 字符 vs 772±74 字符，
   R4 特有的自述用语在两组里出现频次相同；没有「结构激活」这类照抄痕迹。
4. **保留后 R4 均值 0.4982、R4 − R2 = +0.3516**，与论文表 4.5.1 印出的 0.498 / +0.352 一致；
   剔除会让 R4 掉到 0.436 / +0.290，反而与论文不符。

清单见 [`hy3/r4-offset-0.6-list.jsonl`](hy3/r4-offset-0.6-list.jsonl)（含 `resolution: kept_in_statistics`）。
因此 Hy3 的汇总表**只有一张**（「表 1 全量（未剔除任何记录）」），没有敏感性表。

### 4.4　`h_ref` 的口径（**读 κ 之前必看**）

论文口径：PCA-10 → `h_ref` = 池化中位成对距离 → `x` = 条件质心（不做 mean-shift）。

**两个底座各自一个带宽，六个条件共用**：

| 底座 | BGE-M3 | bge-large-zh | gte-Qwen2 |
|:--|--:|--:|--:|
| Step-5-preview（clean 274，**主口径**） | **0.383989** | **0.424054** | **0.461062** |
| Yuanbao Hy3（270 向量池） | **0.421071** | **0.417366** | **0.465423** |

Step-5-preview 另给一套论文印值所用的带宽（354 条池，temp 0.7、无 level 过滤）：
0.369068 / 0.410889 / 0.449884。为什么主口径不用它：**六个条件必须建在同一个记录集上**。
论文 Appendix F 的 Step-5-preview 行里，R1 的 n 是 **126**，其余五个条件是 46/46/45/45/46——

## 5. κ 的算法（一句话版）

```
E(x) = −log p̂(x)                                    高斯核密度估计
∇²E  = I/h² + g gᵀ − A
      g = h⁻² Σ wᵢ dᵢ ,  A = h⁻⁴ Σ wᵢ dᵢ dᵢᵀ ,  dᵢ = xᵢ − x
κ    = λ_min(∇²E)                                   在 x = 条件质心处求值
κ̃    = κ · h²                                        无量纲化
```

- 空间：对该底座的**全部**记录做一次 PCA，取前 10 维（不是每条件各做一次）。
- 带宽：`h_ref` = 该 10 维空间中全部成对欧氏距离的中位数，一个底座一个带宽，六个条件共用。
- 求值点：**条件质心** `x = mean(条件内全部点)`，**不做 mean-shift**。
  （在 mean-shift 收敛点求值会得到差 0.1% 的另一组数，本单元不采用。）
- 单峰判定：在 `h_ref` 下对每个点做 mean-shift，以 `0.5·h` 为合并半径，去重后点数 ≥ 1% 样本数者计为众数。

本单元共 2 底座 × 3 通道 × 6 条件 = **36 个 κ 值，全部为正**；无量纲化后
`κ̃ = κ·h²` 落在 **0.838–0.970**（step-5 0.838–0.947，Hy3 0.906–0.970），
即六个条件在各自带宽下都是实心盆地。
